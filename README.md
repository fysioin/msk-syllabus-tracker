# MPT-MSK Syllabus Checklist

A single-page, offline-capable checklist for the MPT Musculoskeletal Sciences syllabus (Papers I–IV).

## Features
- Every unit and sub-topic across Papers I–IV, tickable.
- **Highlight** any topic with the pen button; filter to highlighted-only to build a revision shortlist.
- **Auto-save** — ticks and highlights are stored in the browser (localStorage) and restored on your next visit.
- **Offline** — a service worker caches the page, so it keeps working with no connection after the first load.
- **Installable** — add it to your home screen / desktop from the browser.
- Stars mark the higher-weight (aggregated) topics; the `(n Q)` badge shows questions per topic in the final theory paper.

## Files
- `index.html` — the app
- `sw.js` — service worker (offline cache)
- `manifest.webmanifest` — PWA metadata
- `icon.svg`, `icon-192.png`, `icon-512.png` — icons

## Hosting
Served as a static site (e.g. GitHub Pages). No build step.

## Note
Weightages follow the MPT question-paper topic-wise blueprint (2021-22 batch onwards).
